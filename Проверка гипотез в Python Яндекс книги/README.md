# Описание проекта
Проект посвящён сравнению частоты использования сервиса «Яндекс Книги» пользователями Москвы и Санкт‑Петербурга. Основная гипотеза: жители Санкт‑Петербурга проводят в приложении больше времени за чтением и прослушиванием книг, чем москвичи. 

# Цель 
Проверить гипотезу о более высокой вовлечённости пользователей из Санкт‑Петербурга по сравнению с Москвой, используя статистические методы анализа.

# Навыки и инструменты
- python
- pandas
- numpy
- seaborn
- matplotlib
- scipy

# Вывод
В рамках проекта я провела A/B‑тест новой версии интерфейса интернет‑магазина BitMotion Kit и оценила её влияние на конверсию в покупку. Моя задача состояла в том, чтобы не просто посчитать разницу в процентах, а дать бизнесу обоснованный, статистически подкреплённый вывод и практические рекомендации.

Ключевые результаты:
Конверсия в тестовой группе (B) — 29,30 %, в контрольной (A) — 27,58 %.
Абсолютный прирост — +1,72 процентных пункта, относительный — +6,23 %.
Эффект статистически значим: p‑value ниже заданного уровня α, нулевая гипотеза отвергнута.
Целевой показатель в 30 % не достигнут (недостаёт 0,7 процентных пункта).
Для одной дополнительной покупки требуется обработать примерно 58 пользователей — эффект умеренный, но практически значимый.
Что было сделано аналитически:

Проверила корректность дизайна теста: баланс групп, отсутствие пересечений, достаточность выборки, чёткие границы горизонта анализа.
Рассчитала ключевые метрики по группам и оценила размер эффекта.
Провела статистическую проверку, интерпретировала p‑value и соотнесла наблюдаемый прирост с минимальным обнаруживаемым эффектом.
Оценила практическую значимость результата через метрику «пользователей на одну дополнительную покупку».
Выводы и рекомендации:

Новая версия интерфейса однозначно лучше текущей: конверсия статистически значимо выросла.
Однако полного достижения целевого показателя нет — нужен следующий шаг.
Рекомендовано поэтапное внедрение с мониторингом метрик, поведенческий анализ для поиска точек роста и серия точечных A/B‑тестов по отдельным элементам интерфейса.
Чему это учит с точки зрения аналитика: даже небольшой, но статистически подтверждённый прирост — это результат, который можно использовать как базу для дальнейших улучшений. В проекте я показала, как соединить строгую статистику с практическими выводами для бизнеса: не просто «стало лучше», а «на сколько, насколько уверенно и что делать дальше».
