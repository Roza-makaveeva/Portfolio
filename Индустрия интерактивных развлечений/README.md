# Описание проекта
Этот инструмент представляет собой комплексное аналитическое решение для отслеживания ключевых показателей, связанных с игровым каталогом, активностью пользователей и ценовой стратегией. Его основная задача — предоставлять актуальные данные для поддержки принятия стратегических решений в области разработки продукта, маркетинга и монетизации.

# Структура и содержание
Панель состоит из четырёх разделов:
- Игровые достижения: На этой странице вы сможете оценить популярность и редкость достижений в разрезе игр и жанров.
- Анализ игр: В этом разделе вы найдёте информацию о количестве игр, их распределении по жанрам, платформам, разработчикам и издателям.
- Анализ игроков: На этой странице представлены данные о географии игроков, их количестве, общем числе установок и самых популярных жанрах.
- Стоимость игр: Здесь можно проанализировать среднюю и медианную стоимость игр по жанрам, а также отследить изменение цен на разных платформах.
- 
Для более детального анализа используйте панель фильтров. Вы можете отфильтровать данные по различным параметрам, таким как период, платформа, жанр, разработчик и другие. Интерактивная фильтрация: Дашборд позволяет фильтровать данные в режиме реального времени. Нажмите на интересующий вас сегмент на любом графике (например, на страну на карте), чтобы мгновенно отфильтровать все остальные графики на странице. Анализ изменения количества игроков из года в год: На странице «Анализ игроков» вы можете увидеть KPI «Изменение количества игроков в годовом исчислении». Для управления этим показателем используйте отдельный фильтр «Месяц (в годовом исчислении)»
