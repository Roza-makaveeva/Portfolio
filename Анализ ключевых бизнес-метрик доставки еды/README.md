# Цель 
Провести анализ ключевых метрик сервиса доставки готовой еды, действующего на территории Саранска, в период с начала мая по конец июня 2021 года.

# Навыки и инструменты
- SQL
- DataLens

# Вывод
Стабилизация клиентского потока. Анализ показал, что резкие спады DAU во многом обусловлены зависимостью от разовых акций и, возможно, сезонными факторами. Для обеспечения предсказуемого роста необходима сбалансированная маркетинговая стратегия, формирующая стабильную активность пользователей вне зависимости от разовых кампаний. Это позволит создать постоянную аудиторию вместо кратковременных всплесков.

Упрощение процесса покупки. Часть пользователей не доводит заказ до завершения, что указывает на барьеры на отдельных этапах воронки — от выбора блюда до оплаты. Устранение этих препятствий является ключевым направлением для повышения конверсии в успешные заказы.

Повышение лояльности и возвращаемости. Текущий уровень удержания пользователей требует усиления. Внедрение программы лояльности, персонализированной коммуникации (напоминания, рекомендации) и качественная отработка первого заказа позволят мотивировать клиентов возвращаться на платформу.

Укрепление сотрудничества с эффективными партнёрами. Рестораны с наибольшим показателем LTV составляют основу прибыльности сервиса. Распространение их успешных практик среди остальных участников платформы способствует повышению общего уровня сервиса и доходности.
