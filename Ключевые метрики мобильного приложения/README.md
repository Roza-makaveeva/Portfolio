# Описание проекта
Цель дашборда — предоставить аналитику по ключевым метрикам мобильного приложения, связанным с рекламными расходами, поведением пользователей и доходностью.

Ключевой аспект исследования — определение эффективности рекламных каналов. В рамках анализа оценивается, какие рекламные инструменты использовались в конкретной сессии и как они повлияли на решение пользователя о совершении покупки. Это позволяет:
- оценить эффективность различных каналов привлечения;
- выявить наиболее результативные рекламные инструменты;
- построить причинно‑следственные связи между рекламными активностями и конверсией.
Таким образом, дашборд объединяет финансовые, поведенческие и маркетинговые метрики для комплексной оценки эффективности продукта.

# Структура и содержание
Панель состоит из четырёх разделов:
- Ключевые метрики: стартовая точка для быстрой оценки эффективности: агрегированные показатели, которые сразу дают понимание, «в плюсе» проект или нет, и где есть потенциал для оптимизации 
- По типу рекламной кампании: фокус на финансовой эффективности рекламных форматов
- По рекламным каналам: анализ источников трафика и вовлечённости пользователей
- По типу устройств: анализ поведения пользователей в зависимости от девайса — важно для приоритизации доработок интерфейса и распределения ресурсов разработки

# Система фильтров
Для гибкости анализа реализованы следующие фильтры:

- Период. Выбор временного диапазона.
Значение по умолчанию: 2019‑05‑01 — 2020‑05‑01 (установлено для снижения нагрузки на источник данных при первоначальной загрузке).
- Гранулярность. Настройка детализации данных.
Значение по умолчанию: месяц (применяется ко всем чартам, кроме «Количество клиентов (MAU) по девайсам» и «Динамика клиентской базы по девайсам, DAU» — для них используется более детальная разбивка).
- Тип рекламы. Позволяет изолированно анализировать отдельные типы рекламных кампаний и сравнивать их между собой.
- Рекламный канал. Нужен для точечного сравнения эффективности источников трафика и поиска узких мест.
- Тип устройства. Даёт возможность смотреть поведение пользователей отдельно по устройствам и принимать решения о доработках UX/UI.

# Аналитическая ценность
В рамках проекта:
- спроектирована структура дашборда так, чтобы он отвечал на ключевые управленческие вопросы: «куда вкладывать бюджет», «какие каналы работают лучше», «на каких устройствах пользователи наиболее активны»
- продумана логика визуализации, чтобы упростить интерпретацию данных и снизить риск ошибок при принятии решений
- настроена система фильтров с разумными значениями по умолчанию — это ускоряет работу с дашбордом и снижает нагрузку на инфраструктуру
- подобраны типы чартов под конкретные аналитические задачи: Line Chart для динамики, Bar Chart для сравнения, Pie Chart для долей — чтобы каждый график решал свою задачу и не перегружал пользователя лишней информацией
