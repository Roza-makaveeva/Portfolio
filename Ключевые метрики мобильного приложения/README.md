# Описание проекта
Цель дашборда — предоставить аналитику по ключевым метрикам мобильного приложения, связанным с рекламными расходами, поведением пользователей и доходностью.

Ключевой аспект исследования — определение эффективности рекламных каналов. В рамках анализа оценивается, какие рекламные инструменты использовались в конкретной сессии и как они повлияли на решение пользователя о совершении покупки. Это позволяет:
- оценить эффективность различных каналов привлечения;
- выявить наиболее результативные рекламные инструменты;
- построить причинно‑следственные связи между рекламными активностями и конверсией.
Таким образом, дашборд объединяет финансовые, поведенческие и маркетинговые метрики для комплексной оценки эффективности продукта.

# Структура и содержание
Панель состоит из четырёх разделов:
- Ключевые метрики: стартовая точка для быстрой оценки эффективности: агрегированные показатели, которые сразу дают понимание, «в плюсе» проект или нет, и где есть потенциал для оптимизации 
- По типу рекламной кампании: фокус на финансовой эффективности рекламных форматов
- По рекламным каналам: анализ источников трафика и вовлечённости пользователей
- По типу устройств: анализ поведения пользователей в зависимости от девайса — важно для приоритизации доработок интерфейса и распределения ресурсов разработки
